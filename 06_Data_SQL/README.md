# Data & SQL

## Current Scope
The functional requirements identify reporting and monitoring needs, but this repository does not currently contain a verified production dataset or SQL execution evidence for MediConnect.

SQL artefacts should be added only when an actual dataset/query workflow has been prepared and can be demonstrated.

## Requirement Alignment
FR-11 identifies reporting needs around:
- Case volume
- Turnaround time
- Approval / denial / pending status
- Stalled or missing-information cases
- Exportable reports

These are documented requirements, not claims of completed analytical execution.
